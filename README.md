# XMRT DAO

Decentralized Monero mining ecosystem. Hardware + software + agent-driven operations.

**xmrtdao.github.io** — organization landing page with live mining stats, fleet status, DAO membership, and the latest from Paragraph.

## Stack
- Static HTML/JS — served via GitHub Pages
- Live data from relay.mobilemonero.com
- RSS feed from paragraph.com/@xmrt
- WHOP membership integration
